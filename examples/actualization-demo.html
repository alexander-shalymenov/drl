What Argmax Does

Argmax ignores text length. It only looks at probability. If Candidate B has the highest probability, Argmax selects Candidate B.

What Actualization Does

Actualization compares probability and text length together. It selects the candidate with the lowest total cost.

How the final answer is selected

Each candidate gets a total cost. The lowest total cost wins.

Total cost = text length + probability penalty

Text length means how many characters are in the answer. Probability penalty is lower when probability is higher.

If two candidates have the same total cost, this demo uses a tie-breaker: it selects the first candidate among the tied candidates.

Where probability comes from

In this demo

Probability is entered manually. The page does not calculate it by itself. The demo is only showing how the final selection rule works.

In a smarter version

Probability would come from a model, search system, scoring engine, or another generator. The user would not type probability manually.

Example of a smarter version

An AI model could generate several possible answers and attach confidence scores to them. A search engine could generate several results and attach relevance scores. A routing system could generate several routes and attach success scores.

Actualization starts after that. It takes those possible outputs and commits to one final output.
